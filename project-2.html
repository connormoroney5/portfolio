ISU Roommate Finder

A native Android app that helps Iowa State students find compatible roommates, built by a team of four.

Add a screenshot or demo video of the app's home screen here

Description

In COM S 3090: Software Development Practices, teams of four built a native mobile application, with the course designed to mirror how software is built in industry. Our app, ISU Roommate Finder, lets students create a profile, see housing announcements, and search for other students with similar preferences.

The frontend is an Android app written in Java and XML in Android Studio. The backend is a Spring Boot server developed in IntelliJ IDEA, with a SQL database, and the two communicate over REST and WebSockets (the latter for real-time features and notifications).

We followed an industry-style workflow: GitLab repositories, a SCRUM task board to track issues and progress, code reviews, automated tests (Espresso for Android, RestAssured for the backend), and CI/CD. We also used Postman to test our API.

My role

Our team had two frontend and two backend developers, and I was one of the frontend developers. After the individual demos, we worked as a group for three team demos. For each one I was responsible for designing two pages of the app. For the third demo I also designed and built the WebSocket connection between the frontend and backend and made sure it worked end to end. Although I focused on the frontend, I learned the backend concepts through lectures and by helping my teammates. I received an award as one of the top developers in the class, along with one of my teammates.
