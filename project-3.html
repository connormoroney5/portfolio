RISC-V processor

A processor designed in VHDL that reads and runs RISC-V instructions, built from gates up with a teammate.

Add the processor block diagram here

Description

CPRE 3810: Computer Organization and Assembly Level Programming had two parts. In the first, I worked alone and used VHDL to build the basic components a processor is made of: logic gates, adders, registers, a register file, and more.

In the second part, a team of two designed a processor that reads and executes RISC-V instructions. Our design includes the pieces you would expect, such as a program counter, instruction and data memory, a decoder, a control unit, a register file, and an ALU, along with hazard detection and forwarding units. Our processor ran the full set of required RISC-V instructions.

My role

With only two people on the team we did not have formal roles, and we each worked in the other's area. I did the majority of the work, mostly the implementation, while my teammate focused more on sketching and designing. We found that many of our bugs could have been prevented with better planning and sketching up front.

Skills and knowledge gained

  • VHDL: building and testing digital components
  • Computer architecture: datapath and control design, and how a processor executes RISC-V instructions
  • Debugging hardware designs and planning before implementing
  • An appreciation for the low-level layers that web development rests on
